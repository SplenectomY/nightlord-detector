# Testing a run

1. Start Nightreign in borderless windowed.
2. `python -m nightlord_detector` — debug console is on by default.
3. Fight a Night 1 boss and watch `raw:` in the debug window.
4. If OCR is empty, move the ROI sliders until the gold nameplate is inside the crop.
5. Confirm Night 1 auto-assigns, then Night 2 on the next night.
6. Overlay should list the same Nightlords as https://nightlord.app/ for that pair.
